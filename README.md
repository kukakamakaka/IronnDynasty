# Ironn Dynasty 🏋️‍♂️

Ironn Dynasty is a full-stack web application designed for fitness monitoring and activity tracking. Built with **Python 3.10** and **Django**, it provides a seamless experience for users to manage their fitness journey.

🔗 **Live Demo:** [onege.pythonanywhere.com](https://onege.pythonanywhere.com/)

---

## 🌟 Key Features

### 📊 Personal Dashboard
The "heart" of the project. A dedicated space where users can see their personal activity, aggregated data, and progress. Built with optimized Django ORM queries to ensure fast loading times.

### 🌗 Adaptive UI (Dark/Light Mode)
Supports dynamic theme switching. 
- **Dark Mode:** High-contrast "Iron" style for gym environments.
- **Light Mode:** Clean look for bright daylight.
- *Tech:* Implemented with JavaScript for state persistence.

### 🔐 User Management
Full authentication cycle:
- Secure Registration and Login.
- Profile management and data privacy.
- Protected routes using Django’s permission system.

---

## 🛠 Tech Stack

- **Backend:** Python 3.10, Django (MVT Architecture)
- **Database:** SQLite (optimized for production performance)
- **Frontend:** JavaScript, HTML5, CSS3 (Responsive Design)
- **Tooling:** Node.js, npm, Virtualenv
- **Deployment:** PythonAnywhere (WSGI, SSL, Static/Media management)

---

## 📁 Project Structure

- `fitness/`: Main app logic (models, views, and fitness tracking functionality).
- `djangoProject/`: Core settings and configuration.
- `templates/`: Clean and modular HTML structures.
- `static/`: Organized CSS, JS, and image assets.
